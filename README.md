# 仓储 AMR 补货搬运方案设计

这是一个个人方案设计案例，研究范围是“存储区取箱 -> AMR 搬运 -> 拣选区输送线接箱”。它不是客户交付或现场实施记录，也没有真实仓库的运营数据。文中的数量、距离和节拍均为明确标注的设计输入，用于展示需求拆解、容量测算、系统接口和验收设计的方法。

## 阅读顺序

1. [案例分析](case_study.md)：输入条件、方案取舍、车辆测算、接口边界、异常流程、敏感性分析和验证计划。
2. [方案 PDF](pdf/amr_warehouse_solution.pdf)：适合投递和阅读。
3. [展示 PPT](ppt/amr_warehouse_solution.pptx)：适合讲述设计思路。

## 项目边界

- 个人完成的是方案分析和材料编写；没有开发 WMS/WCS/RCS、编写 PLC 程序、调试 AMR 或参与供应商选型采购。
- 测算得到的是方案容量，不是现场效率提升。测试用例是计划执行的验收方法，不是已经通过的测试。
- 现场通道、网络、设备参数、接口协议和安全评估均需要在真实项目中核实。

## 简历写法

**仓储 AMR 补货搬运方案设计 | 个人专题项目**

围绕存储区至拣选区的料箱补货，建立搬运量、路线、交接节拍等设计输入，完成 AMR 与固定输送线的方案取舍和车辆容量测算；梳理 WMS/WCS/RCS、AMR 与 PLC 的任务及状态边界，设计设备未就绪、扫码不一致等异常处理和验收用例，输出方案 PDF 与展示 PPT。所有数量均为课题假设及测算结果，未进行现场部署。
