# 5 天学习与实施计划

## 第 1 天：概念补齐

学习 AMR、AGV、WMS、WCS、RCS、PDA、扫码复核、货到人和人到货的基本概念，并整理术语表。

## 第 2 天：流程与架构

画出订单下发、任务分配、AMR 搬运、拣选、复核出库的业务流程图；补充系统架构图，明确 WMS/WCS/RCS/设备之间的数据边界。

## 第 3 天：方案 PDF

完成方案说明书主体，包括项目背景、客户需求、总体架构、业务流程、设备组成和系统集成方式。

## 第 4 天：清单与验收

补充设备清单、风险清单、异常处理机制、实施里程碑和验收指标。

## 第 5 天：资料整理

整理 README、图表、PDF 和项目描述，上传到 GitHub 或网盘，形成完整资料包。
