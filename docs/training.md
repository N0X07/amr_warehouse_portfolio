# 现场培训材料

## 培训对象

- 仓库主管：关注效率指标、异常闭环和班组协同。
- 一线操作员：关注任务接收、扫码复核、异常上报和安全避让。
- 运维人员：关注设备上线、网络检查、充电策略、日志定位和日常巡检。

## 培训内容

- AMR 安全规则：避让、急停、禁入区域、异常声光提示。
- WMS/WCS 操作：任务查看、任务暂停、优先级调整、异常处理。
- 拣选复核：扫码枪/PDA 使用、货位校验、订单复核、差异上报。
- 日常巡检：电量、轮组、传感器、网络、充电桩和通道障碍物。

## 考核方式

每位操作员完成一次入库搬运、一次拣选搬运、一次异常订单上报和一次复核出库演练。
