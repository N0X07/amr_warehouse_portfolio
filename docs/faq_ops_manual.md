# FAQ 与运维手册

## AMR 无法接单怎么办？

检查设备是否在线、电量是否低于调度阈值、是否处于急停或故障状态；再检查 WCS 任务队列和网络连接。

## 路径拥堵怎么办？

先查看拥堵点是否有障碍物或人工占道；必要时临时关闭该路径，并通过 WCS 调整任务优先级或绕行策略。

## 网络中断怎么办？

AMR 应进入安全停车或本地避障状态。运维人员检查 AP、交换机、VLAN、DHCP 和边缘工控机连接，恢复后核对任务状态。

## 错拣或漏拣怎么办？

通过扫码复核拦截异常订单，生成异常工单，人工确认库存和货位后重新下发补拣任务。

## 日常巡检清单

- 每班检查 AMR 电量、急停按钮、传感器窗口、轮组磨损。
- 每班检查通道障碍物、充电桩状态、扫码枪电量和网络覆盖。
- 每日导出任务成功率、异常处理时长、设备在线率。
