# 仓储 AMR 搬运/分拣方案 Demo

## 1. 项目背景

本项目以中型仓库为假设场景。仓库 SKU 较多，订单波动明显，入库上架、拣选补货、复核出库之间存在较多人工搬运。现有流程依赖人工叉车、地牛或推车，容易出现搬运等待、错拣、路线交叉、旺季扩容困难等问题。

方案目标是梳理 AMR 小车、货架/输送线、WMS/WCS、RCS 调度、PLC、扫码复核和现场看板之间的关系，形成“订单驱动、任务拆解、设备执行、状态回传、异常闭环”的仓储自动化流程。

## 2. 客户需求

- 降低重复搬运人工投入，减少人员在库区长距离行走。
- 提升入库上架、拣选搬运和复核出库周转效率。
- 减少错拣、漏拣和货位不一致问题。
- 支持旺季订单增长时横向增加 AMR 和拣选工位。
- 形成可验收、可培训、可运维的交付材料。

## 3. 方案设计

系统采用四层结构：业务系统层、控制调度层、执行设备层、数据运维层。方案中特别关注上层软件任务与现场控制信号的衔接，例如 WCS 与 PLC、输送线、扫码设备、传感器和 AMR 到站信号之间的状态闭环。

- WMS 负责订单、库存、货位、波次和任务源。
- WCS/RCS 负责任务分解、路径规划、交通管制、充电策略和设备状态管理。
- AMR、输送线、扫码枪、PDA、机械臂或人工拣选工位负责现场执行。
- PLC 负责输送线、提升机、挡停器、光电传感器、急停、安全光栅等现场 IO 控制与状态采集。
- 监控看板、日志、异常工单和报表负责运营优化。

## 4. 标准流程

订单下发后，WMS 根据库存和波次生成拣选/搬运任务，WCS 将任务拆解为 AMR 搬运、到站等待、人工或机械臂拣选、复核、出库交接等子任务。调度系统根据车辆位置、电量、路径拥堵情况分配 AMR。每个关键节点通过扫码或传感器回传状态，最终形成可追踪闭环。

## 5. 风险控制

关键风险包括路径拥堵、网络中断、充电调度不合理、异常订单、人工协同失误和设备离线。方案通过单向主通道、缓冲区、任务优先级、低电量阈值、离线降级、异常工单和人工复核机制降低风险。

## 6. 验收指标

建议从任务成功率、平均搬运时长、设备在线率、异常处理时长、错拣率和系统数据一致性进行验收。试运行期建议覆盖至少 5 个连续工作日，并包含高峰波次、补货任务、异常订单和低电量充电场景。
